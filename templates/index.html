    CropCare AI — University Viva & Architecture Guide

    1. Why Scikit-Learn (36 Quantitative Features) instead of a Deep Learning CNN? ▼
    Modern Python (3.14 on Windows) lacks precompiled TensorFlow binaries. Instead of fake predictions, CropCare AI implements an authentic computer vision pipeline using Pillow and Scikit-Learn that calculates 36 quantitative botanical features (RGB/HSV moments, Green Leaf Index, VARI, tissue chlorosis/necrosis ratios, and Sobel gradient textures). Inference executes locally in <50 milliseconds without GPU requirements.
    2. How is data structured and persisted? ▼
    We use SQLite 3 across three relational tables: scans (diagnostic history), crops (managed fields), and farm_tasks (crop calendar). 100% of queries use ? parameterization to prevent SQL injection vulnerabilities, and foreign key cascading ensures deleting a crop automatically cleans up linked calendar tasks.
    3. How does the biological leaf validation guard prevent false classifications? ▼
    Before classification, the model engine executes an automated botanical validation guard in services/inference_service.py. It inspects chlorophyll pixel dominance and vegetation color variance. Images lacking botanical foliage (e.g., cars, faces, blank surfaces) are rejected with an explanatory error message instead of hallucinating a diagnosis.
    4. How is the Open-Meteo Weather API integrated safely? ▼
    Open-Meteo is an open-source, non-commercial meteorological service that does not require paid API keys. The Flask backend queries coordinates for Pakistan's agricultural districts with in-memory TTL caching (10 minutes) and computes a chemical spray safety window: wind speed must be below 15 km/h to prevent dangerous drift, precipitation must be 0 mm, and temperatures must be under 36°C.
    5. Recommended 4-Minute Viva Demonstration Sequence ▼
    1. Show the Overview Dashboard with real-time weather and spray conditions for Lahore or Multan.
    2. Click the Language Toggle ("اردو میں دیکھیں") to demonstrate complete Right-to-Left (RTL) localization for Pakistani farmers.
    3. Go to Crop Diagnosis and click "Tomato Early Blight" from the presentation sample tray. Show the 36-feature confidence meter, symptoms, and organic prevention advice.
    4. Navigate to Farm Records to verify the scan record was persisted in local SQLite.
